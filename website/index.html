深入了解更多

⚙️

严格按照国家标准

基于 GB/T 9704-2012《党政机关公文格式》标准实现，覆盖标题、正文、附件、落款等全部格式要素。

  • 标题自动设为一号，方正小标宋简体
  • 正文设为三号，仿宋_GB2312 字体
  • 英文与数字使用 Times New Roman
  • 全面设置字体 XML 四维属性（ascii / hAnsi / eastAsia / cs）
  • 页边距、行距、段落缩进等自动校对
🧠

多 AI 模型支持

兼容 OpenAI、DeepSeek、Claude、Ollama 等主流大模型，自由选择 AI 引擎

📁

三级模板体系

official < custom < user 三层深度合并，灵活覆盖官方与自定义风格

📐

Parser → Model → Generator

文档通过 DocumentModel 中间表示流转，各模块职责清晰，解析精准

🔄

可追溯的修复记录

每一次检查与修复均有记录，支持版本历史回溯，随时还原到任意版本
