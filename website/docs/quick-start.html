快速开始

在最短路径内体验文枢的核心工作流：安装、检查、修复、导出。

本页目录
安装与启动 上传文档 检查格式 修复问题 AI 润色 导出文档 构建安装包

第一步：安装并启动

方式一：一键启动（推荐）

下载最新版安装包后双击运行，打开即可看到工作台界面。首次启动会自动初始化后端服务，稍等片刻即可使用。

支持平台：Windows x86_64 · macOS Intel / Apple Silicon · Linux x86_64 / ARM64

方式二：从源码运行

适合开发者和信创环境用户：

# 1. 克隆仓库
git clone https://github.com/linhut/document-ai-assistant.git
cd document-ai-assistant

# 2. 安装后端依赖
cd backend
pip install -r requirements.txt

# 3. 启动后端服务（端口 8765）
python main.py

# 4. 新终端：安装前端依赖并启动
cd frontend
npm install
npm run electron:dev

环境要求

从源码运行时，请确保已安装以下依赖：

  • Python ≥ 3.12
  • Node.js ≥ 20
  • Git

第二步：上传文档

进入文档处理页面，将 .docx 文件拖入上传区域，或点击选择文件。

  • 支持批量上传多个文档
  • 系统自动检测文档类型（通知、请示、报告等 22 种法定文种）
  • 文件仅在本机处理，不会上传到云端
💡 .doc 或 .wps 格式需要系统安装 LibreOffice 以自动转换。
Windows 下推荐直接使用 .docx 格式。

第三步：检查格式

上传完成后，点击检查格式按钮。系统将基于 GB/T 9704-2012《党政机关公文格式》 标准执行全面扫描：

  • 字体检测 — 标题是否使用方正小标宋简体，正文是否为仿宋_GB2312
  • 字号检测 — 标题一号（26pt）、正文三号（16pt）等
  • 段落检测 — 行距、首行缩进 2 字符、对齐方式
  • 页面检测 — 页边距、纸张类型（A4）、页码格式
  • 结构检测 — 版头、主体、版记三部分完整性

检查完成后，校审中心会列出所有发现的问题，按严重程度分级：

  • P0（格式错误） — 必须修复，如字体不符、字号错误
  • P1（轻微问题） — 建议修复，如行距偏差
  • P2（优化建议） — 可选改进

第四步：一键修复

在校审中心勾选需要修复的问题，点击应用修复：

  • 字体自动替换（设置全部 4 个 XML 字体属性：ascii / hAnsi / eastAsia / cs）
  • 段落间距、行距、缩进自动校正
  • 页边距恢复国家标准值
  • 多余空格、空行自动清理
  • 每次修复生成新版本，支持回退

第五步：AI 智能润色（可选）

如需进行语义级优化，可配置 AI 服务商：

  • 进入 AI 配置 页面
  • 选择服务商：DeepSeek、通义千问、OpenAI、Claude、Ollama 等 23+ 家
  • 填入 API Key（加密存储于本机）
  • 点击测试连接验证可用性

配置完成后，AI 分析会：

  • 按 22 种公文文种定制检查规则
  • 发现规则引擎无法识别的语义问题
  • 提供修改建议（可勾选后一键应用）

第六步：导出成稿

确认所有修复无误后，点击下载按钮：

  • 导出符合 GB/T 9704 标准的 .docx 正式文档
  • 支持 A4 实时预览，所见即所得
  • 版头版记完整保留（发文机关标志、红色反线、抄送等）
💡 也可使用 A4 实时排版预览 功能，左侧调参右侧即时预览，确认满意后再下载。

构建桌面安装包

如需自行构建分发给其他用户：

# Windows 安装包
cd frontend
npm run electron:build:preview
# 输出: frontend/release/AI公文智能优化助手 Setup X.X.X.exe

# Linux x86_64
npm run electron:build:linux
# 输出: *.AppImage + *.deb

# Linux ARM64（鲲鹏/飞腾）
npm run electron:build:linux:arm64
